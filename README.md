# Odin-Hash-Map

A simple excercise to create a HashMap Class to store Hashed Values.

The class (Created in index.js) has the following classes/functions.

# Class HashMap()

Use `const x = new HashMap();` to create a new Hash map. The name of the Hash map is 'x'.

The HashMap() class has the following available functions:

## set()

Use x.set(key, value) to set a new hashed value with the associated key.

## get()

Use x.get(key) to get the value that has been hashed using that key.

## has()

Use x.has(key) to check if this key exists in the hash map.

## remove()

Use x.remove(key) to remove this key and its value from the hash map.

## length()

Use x.length() to check the number of entries in the hash map.

## clear()

use x.clear() to clear all entries from the hash map.

## values()

use x.values() to get an array of all the values stored in the hash map

## entries()

use x.entries() to get an array of all the key-value pairs stored in the hash map
